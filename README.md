
# Ubuntu Home Lab & Media Server

A self-hosted home lab built with Ubuntu Server on a GMKtec NucBox G9 mini PC. This project documents my hands-on experience with Linux system administration, networking, media services, and troubleshooting.

## Project Overview

I built this home server to learn Linux administration while creating a practical media streaming and file-sharing environment. The system runs without a desktop interface and is administered remotely through SSH.

## Hardware

- Device: GMKtec NucBox G9
- Processor: Intel N150
- Memory: 12 GB RAM
- Storage: 512 GB SSD
- Operating System: Ubuntu Server

## Technologies

- Ubuntu Server — Linux operating system
- Jellyfin — Self-hosted media streaming
- Samba — Network file sharing
- OpenSSH — Remote server administration
- Linux networking — Local network connectivity and troubleshooting

## Implemented Features

- Headless Ubuntu Server installation and administration
- Jellyfin media streaming to supported devices
- Samba network file sharing
- SSH-based server management
- Troubleshooting of client connectivity and playback issues

## Planned Improvements

- Secure remote access using Tailscale
- System monitoring and resource utilization tracking
- Improved service documentation and troubleshooting guides
- Exploration of Ubuntu Pro security features

## Skills Demonstrated

Linux administration, command-line operations, networking, troubleshooting, self-hosted services, and technical documentation.

## Project Status

Active home lab — documentation and infrastructure improvements in progress.
